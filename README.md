# 🏡 Luxury Real Estate Landing Page

A modern and responsive luxury real estate landing page inspired by premium real estate websites. This project focuses on creating an elegant user interface with a fullscreen hero section, modern typography, and smooth navigation.

## 🌐 Live Demo

👉 https://sanjana952.github.io/real-estate-landing-page/

---

## ✨ Features

- Responsive Design
- Modern Luxury UI
- Fullscreen Hero Section
- Transparent Navigation Bar
- Property Location Buttons
- Social Media Sidebar
- Smooth Hover Effects
- Clean HTML, CSS & JavaScript
